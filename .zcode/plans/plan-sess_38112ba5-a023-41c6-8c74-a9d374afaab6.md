## §1. PRD — UX đã chốt (Giai đoạn 1)
Web app PC + Mobile: chụp ảnh biển bảng giá → AI tái tạo mẫu vector A4 → sửa bằng lệnh tự nhiên + chạm nhanh → xuất PDF chuẩn in / batch / kho mẫu.

- **Mobile**: pill bar nổi "Sửa bằng AI…"; tap mở khay chip gợi ý + lịch sử (không che tờ A4); gửi xong auto-collapse
- **PC**: sidebar phải cố định (cùng 1 component, CSS responsive)
- **Quick Tap**: chọn element → menu Sửa chữ / Đổi màu / Xóa / Tầng / "AI sửa mục này"; sửa chữ = local, 0 lượt AI
- **Tap × AI hybrid**: chip 🎯[element] khi đã chọn; không chọn → AI tự suy luận toàn bảng (intent riêng)
- **Kết quả AI**: auto-apply + highlight vùng đổi + Undo
- **Hoàn tác**: undo stack ~20 bước + snapshot mỗi lệnh AI + nút "Lưu vào Kho mẫu"
- **Voice**: chat-only MVP

## §2. ENGINE (Giai đoạn 2)
**Document JSON v1** (`schemaVersion:1`, mm tuyệt đối, A4 210×297): element types `text | rect | line | image | path | repeat`; TextEl có `fitMode:'shrink-to-fit'|'wrap'`, `maxLines`; RepeatEl có `dataBinding{source:'items'}`, `itemTemplate` chứa `{{field}}`, `grid{cols,gapX,gapY}`, `overflow:'paginate'`; field `dataBinding` đặt sẵn trên mọi element.

**Patch theo id** (không array index): `{op:'update',id,path:'props.fill',value}` + `add` (id client cấp) / `remove`. Patch = diff → highlight miễn phí.

**Auto-fit**: Canvas `measureText` + binary search fontSize sau `document.fonts.ready`; font OFL (Be Vietnam Pro / Montserrat / Anton).

**Chuẩn xác 100%**: `responseSchema` (cú pháp) → Zod (giá trị: hex màu, tọa độ trong khổ, id tồn tại) → auto-retry 1 lần kèm lỗi.

## §3. BATCH + KHO MẪU (Giai đoạn 3)
- 1 lượt AI tách `items[{name,price,unit,discount?}]` + confidence → engine dàn N trang qua node repeat → **1 file PDF nhiều trang**
- Cổng confidence: ≤5 item & cao → auto-apply; ≥6 hoặc ô yếu → bảng "Duyệt dữ liệu" (sửa trực tiếp, ô yếu vàng)
- **Renderer kép client-side**: SVG preview + PDF vector `pdf-lib` (mm→pt ×2.8346; A4=595.28×841.89pt; font subset tiếng Việt)
- Kho mẫu: thumbnail canvas→PNG + AI TAG_TEMPLATE + chip filter; cột `embedding` (pgvector) chờ bật semantic search khi kho ≥30 mẫu

## §4. STACK & VẬN HÀNH (Giai đoạn 4)

## §5. DATABASE SCHEMA
```sql
create extension if not exists vector;

create table templates (
  id uuid primary key default gen_random_uuid(),
  owner uuid not null references auth.users(id) on delete cascade,
  name text not null,
  doc jsonb not null,
  thumbnail_path text, source_photo_path text,
  tags text[] not null default '{}', description text,
  schema_version int not null default 1,
  embedding vector(768),
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create index templates_tags_gin on templates using gin(tags);
create index templates_owner_idx on templates(owner);

create table snapshots (
  id uuid primary key default gen_random_uuid(),
  template_id uuid not null references templates(id) on delete cascade,
  doc jsonb not null, label text,
  created_at timestamptz not null default now()
);

create table extraction_cache (
  photo_hash text primary key,
  doc jsonb not null,
  created_at timestamptz not null default now()
);

create table ai_usage (
  id bigint generated always as identity primary key,
  user_id uuid references auth.users(id), ip_hash text,
  intent text not null, ok boolean not null default true,
  created_at timestamptz not null default now()
);
create index ai_usage_user_day_idx on ai_usage(user_id, created_at);

alter table templates enable row level security;
create policy "owner crud" on templates for all
  using (auth.uid() = owner) with check (auth.uid() = owner);
alter table snapshots enable row level security;
create policy "owner crud" on snapshots for all
  using (exists (select 1 from templates t where t.id = template_id and t.owner = auth.uid()));
-- extraction_cache & ai_usage: chỉ truy cập qua service role trong API route
```

## §6. SYSTEM PROMPTS — 5 intent
PREFIX TĨNH (giống hệt mọi lượt): vai trò engine biển bảng giá VN · chỉ xuất JSON hợp lệ, không giải thích · design tokens (3 font token, palette in an toàn, margin 8mm, cỡ chữ tối thiểu) · hierarchy GIÁ > % GIẢM > TÊN HÀNG > phụ chú · quy tắc số VN (15.000đ / 15K, % nguyên số).

1. **EXTRACT**: ảnh → A4Doc (kể cả path họa tiết), ≤60 element/trang, kèm confidence từng element
2. **TARGETED_EDIT**: 1 element + lệnh → Patch[] chỉ đụng id đó
3. **BOARD_EDIT**: bảng element thu gọn + lệnh → Patch[] toàn cục
4. **BATCH_EXTRACT**: câu dài → items[] + confidence từng item
5. **TAG_TEMPLATE**: doc thu gọn → {name, description, tags[]}
